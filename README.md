# 📊 Diwali Sales Analysis Using Excel

## 📌 Project Overview
This project analyzes Diwali sales data using Microsoft Excel to explore product performance, customer demographics, and regional sales trends. An interactive dashboard presents key metrics through charts and visualizations.

## 🎯 Project Objectives
- Analyze sales quantities across product categories.
- Explore sales performance across different states.
- Compare sales across geographical zones.
- Examine sales patterns across customer age groups.
- Present findings in a visual Excel dashboard.

## 🛠️ Tools & Skills
- Microsoft Excel
- Pivot Tables
- Data Analysis
- Data Visualization
- Dashboard Design

## 📈 Dashboard Highlights
The dashboard includes:
- Total quantity by product category
- Total sales amount by product category
- Top five states
- Average sales amount by zone
- Zone-wise sales amount
- Sales by age group

## 📁 Project File
**`DIWALI SALES 2.xlsx`** — Excel workbook containing the sales analysis and dashboard.

## 💡 Key Learnings
- Summarizing sales data using Pivot Tables.
- Comparing sales across product categories and regions.
- Creating charts to communicate business information.
- Presenting analysis through a dashboard.
